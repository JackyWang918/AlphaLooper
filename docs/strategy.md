# 首轮策略约定

更新：2026-09-21。行情接入、试算和显式事件模拟已实现，没有接入真实交易执行。

## 已确定的方向与参数

用户要的是根据历史数据估算合理价格、挂单等待成交、超时撤单重新估价；不以快速买入卖出为默认目标。

| 项目 | 当前约定 |
| --- | --- |
| 每轮买入金额 | 50 U，当前测试交易对为 USDT |
| 每日积分目标 | 32,768 分（用户最新更正，替代此前的 32,678） |
| 积分累计口径 | 按用户提供的规则，仅实际买入成交金额计入，每买入 1 U 计 4 分；卖出不计分，部分成交只计已成交买入金额 |
| 对应每日累计买入成交额 | 8,192 U；积分按用户提供的倍率估算，尚未核验平台实际积分 |
| 买单超时 | 允许追随行情，使用最新数据重新计算买价 |
| 等待时间初值 | 每张普通买/卖单 5 分钟，重挂重新计时；总持仓时长另计 |
| 持仓超时退出 | 从本轮首笔买入成交开始计时，满 30 分钟仍有持仓即转主动退出，不要求先触发 2% 亏损阈值；部分成交、撤单重挂不重置该计时 |
| 每日达标收尾 | 达到 32,768 分后停止新买入，剩余持仓转主动退出、优先尽快清仓，卖完后结束当天任务 |
| 卖出可回本时 | 参考当前卖一挂单 |
| 卖出尚未回本、未触发退出时 | 根据历史数据重新计算卖出挂价 |
| 亏损阈值 | 百分比，2% |
| 亏损检查频率 | 每分钟结束后检查，不是每个行情变化时检查 |
| 触发退出后 | 优先尽快卖出，允许继续依据最新买盘调整价格，直到剩余持仓卖完 |
| 主动退出报价候选 | 用户举例使用买盘第 6 档价格；应理解为第 6 个价格档位，不是第 6 张订单，具体档位参数待最终确定 |
| 整场测试累计损耗预算 | 不超过 10 U；不能未经用户同意提高预算 |

回本参考卖一并不保证在该价格成交或最终回本。2% 是退出触发阈值，10 U 是预算目标，不能承诺实际损失绝不越过它们；分钟检查间隔、价格变化、手续费与退出执行都可能造成超出。不要擅自把用户选定的每分钟检查改成连续检查。

## 待验证的估价方法

助手提出的首个候选：使用 1 分钟 K 线，按窗口成交额之和 / 成交量之和计算价格中心，再用波动尺度乘以偏移系数得到买卖偏移。

```text
买入候选价 = 价格中心 - 买入偏移
未回本且未触发退出时的卖出候选价 = 价格中心 + 卖出偏移
```

该方法尚未通过数据或实盘证明有效。窗口长度、波动计算方式、买卖偏移系数、新数据是否额外加权等未定，不得描述为已经验证的最优参数。回本卖一、达到阈值主动退出优先于普通卖出模型。

## 已确认的执行细节

1. 每张普通挂单等待 5 分钟，重挂重新计时。
2. 买单部分成交后到期，撤掉剩余买单，先卖已买入部分，不补足 50 U。
3. 损耗包含费用与剩余持仓按盘口估算的退出亏损。模拟以本轮实际投入成本为分母，已卖出净收入也计入。
4. 达到预算时停止新买入，已有持仓继续退出，不能直接停掉持仓处理。
5. 用户已确认持仓 30 分钟触发主动退出，以及每日积分达标后尽快清仓。30 分钟限定的是进入主动退出的时间，不保证届时已成交清仓；退出后持续按最新买盘处理剩余持仓。这两条规则已接入模拟器并测试，尚未接入真实执行。

## 当前试验参数与假设（可配置，不等于最优或已获实盘确认）

- 15 根已收盘 1 分钟 K 线作为窗口；中心为窗口成交额 / 成交量，不额外做时间衰减。
- 波动尺度为窗口收盘价的总体标准差（价格单位）；买卖偏移系数各为 0.5。
- 买价向下、普通卖价向上按价格步长取整；数量向下按数量步长取整。
- 用户于 2026-09-21 核对平台后提供买入、卖出手续费各 0.01%；界面默认值据此设为每侧 1 基点，并随输入实时显示百分比，仍需手动确认。此费率为用户提供，非系统自动查询。模拟费用以计价币计算；实际用代币扣费等机制待成交接入后核实。
- 50 U 作为含假设买入费的单轮资金上限；卖出费在卖出收入中扣除。
- 主动退出默认买盘第 6 档，15 秒再尝试改单。少于六档使用最深可见档，不保证成交。深度不足时亏损标为未知，分钟检查时进入退出；不是按零亏损处理。
- 主动退出状态保持到清仓。剩余数量不足最小委托量/金额时提示人工处理，不能标记为清仓。
- 累计预算采用各已结束亏损轮次之和，盈利不补回预算（保守试验口径）；再加本轮预计退出亏损评估风险。
- 开新轮预留取 max(配置预留 2 U，单轮金额 × [2% 阈值 + 双侧假设费率])。达到预算或预留不足停止新买入；无法保证跳价后的绝对损失上限。
- 盘口超 15 秒不可试算；交叉/锁定盘口或历史买价触及卖一时暂停新买入。Alpha 为竞价撮合，不把深度价格当成确定可成交报价。
- 每日统计重置时间、运行时间段、真实退出改单频率及上述模型参数仍需确认。

## 如何验证当前实现

控制台“行情与策略研究”按交易链接拉取行情，展示 K 线、成交量、六档盘口、建议价格与数据时间。可以手动或每 10 秒刷新。计算与模拟不会调用浏览器执行器。

沙盒的时间按钮推进虚拟时钟，跨自然分钟边界时进行损耗检查。跳过多个分钟只代表按最新快照进行一次检查，不能推断跳过期间的市场变化。订单成交量与成交价由用户显式输入，不从 K 线推断成交。撤单分请求和确认两步，期间允许输入迟到成交。任务、参数、委托、成交和事件保存在 SQLite，刷新后可恢复。每个模拟任务独立累计，不跨日自动清零；不是后台持续运行或历史回测。

对应代码：`backend/app/market.py`（公开行情）、`backend/app/strategy.py`（纯试算及模拟）、`backend/app/research_api.py`（API）、`frontend/src/components/ResearchPanel.vue`（页面）。

## 实施约束

- 撤单后先确认最终成交量与剩余量，再重新挂单，防止撤单期间的成交导致数量错误。
- 主动卖出采用更积极的限价也可能部分成交，不把买盘第 6 档理解为保证全部成交。
- 不为讨论策略自动执行真实买卖。先完成参数确认、实现及模拟验证，再由用户看护验收真实提交。

## 持久化统计口径

- 买入成交额为数量 × 实际录入成交价，不含手续费；预计积分为累计买入成交额 × 倍率。卖出不计分。
- 模拟手续费以计价币单列；买入费计入持仓成本，卖出费从卖出收入扣除。部分卖出按移动平均成本分摊，清仓分摊剩余全部成本。
- 累计盈亏 = 已实现盈亏 + 剩余持仓按可见买盘退出的预计浮盈亏（含退出费）。深度不足或盘口过期时浮盈亏及累计盈亏显示未知，已实现盈亏仍保留。
- 最后一笔模拟买单尽量缩至剩余目标，按交易步长和最小委托量向上取整，可能略超目标，仍受单轮预算限制；撤单期间迟到成交同样计入积分和持仓。
- 达标或持仓超时后先请求撤销已有单，确认最终成交量后转主动退出；不在撤单结果未知时叠加新委托。

## 真实订单统计的最新确认

用户确认使用平台订单汇总的实际成交数量/金额，按订单 ID 去重更新；无需逐笔明细核验。买卖两侧手续费均以实际成交额 × 0.01% 估算，显示“估算手续费”“预计已实现盈亏”。预计积分仅为买入额 × 4，不计卖出。不将手续费明细或费用币种的精确获取作为本阶段前提。

## 单笔执行约束（2026-09-22 用户确认）

没有人工订单穿插；同时仅一笔单向委托。每分钟巡检当前委托，消失后只核对第一笔最新历史订单的实际结果并回填原委托，再决定下一步。不开发历史订单批量同步。此流程待接入真实执行；已有的五分钟超时、三十分钟持仓退出和达标清仓规则保持。
